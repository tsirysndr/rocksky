# Library provider logos

PNG files are transparent raster exports of the accompanying SVG files.

- Navidrome and Jellyfin: existing provider artwork from `music-player/desktop/assets/icons`.
- Kodi: existing artwork from `rockbox-zig/macos/Rockbox/Assets.xcassets/kodi.imageset`.
- UPnP: generic access-point icon from `rockbox-zig/gpui/assets/icons`.
- Plex: Plex brand icon from the Simple Icons project (`icons/plex.svg`).

Provider names and logos identify compatible third-party servers.
